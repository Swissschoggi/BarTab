# Bartap

Bartap is a crowdsourced iOS app for discovering drink prices at bars.

Users can:
- Find nearby bars
- See current drink prices
- Submit prices they've observed
- Help build a shared database of bar prices

## Status

Early development. Bartap is not on the App Store yet: I can't afford Apple's yearly developer fee right now. If you'd
like to help, you can donate at https://ko-fi.com/bartap.
